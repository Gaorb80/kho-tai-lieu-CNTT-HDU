# 📥 Chưa phân loại

Thư mục này dùng để **tạm chứa tài liệu** khi bạn chưa chắc nên đặt vào đâu trong cấu trúc học kỳ/môn học.

Cứ thoải mái bỏ file vào đây — không cần lo đúng sai. Sẽ có người xem lại và sắp xếp vào đúng thư mục sau.

**Gợi ý (không bắt buộc):** đặt tên file có kèm môn học/học kỳ nếu bạn biết, để dễ sắp xếp hơn. Ví dụ:

```text
de-thi_co-so-du-lieu_ky-3.pdf
ghi-chu_mang-may-tinh.md
```

Không biết cũng không sao — cứ để nguyên tên gốc, thêm vài dòng mô tả trong Issue/PR là được.
