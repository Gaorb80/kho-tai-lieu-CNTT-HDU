# MỤC LỤC ÔN THI THỰC HÀNH CÔNG NGHỆ SỐ(WORD & EXCEL)

## BÀI THỰC HÀNH SỐ 2: KỸ THUẬT SOẠN THẢO VĂN BẢN
### 2.1. Bài tập có hướng dẫn
- [ ] **Bài 1:** Soạn thảo "CÔNG NGHỆ SỐ LÀ GÌ?" (Định dạng chữ, lưu tệp, tạo gõ tắt AutoCorrect, giãn dòng, xuất PDF).
- [ ] **Bài 2:** Soạn thảo "An sinh số" (Định dạng trang in, chèn hình ảnh, tạo gõ tắt, sao chép/di chuyển khối văn bản).
- [ ] **Bài 3:** Soạn thảo "BÀI HỌC VỀ CÔNG THỨC TOÁN HỌC" (Sử dụng Equation chèn công thức toán học, thiết lập lề).
- [ ] **Bài 4:** Tạo và định dạng bảng biểu "KẾT QUẢ HỌC TẬP" và bảng thống kê cấp quản lý.
- [ ] **Bài 5:** Tạo các bảng biểu phức tạp (Bảng giá, Chương trình du lịch, Tuyển thành viên CLB) và ngắt trang.

## BÀI THỰC HÀNH SỐ 3: KỸ NĂNG XỬ LÝ VÀ TỔ CHỨC TÀI LIỆU SỐ
### 2.1. Bài tập có hướng dẫn
- [ ] **Bài 1:** Vẽ sơ đồ cấu trúc máy tính và sơ đồ mạng máy tính (Sử dụng Shapes).
- [ ] **Bài 2:** Soạn thảo "CHỨNG CHỈ TIN HỌC" và chia cột báo (Columns) cho văn bản "TRÍ TUỆ NHÂN TẠO".
- [ ] **Bài 3:** Trình bày "ĐƠN XIN HƯỞNG TRỢ CẤP XÃ HỘI" (Sử dụng Tab set để định dạng khoảng cách).
- [ ] **Bài 4:** Soạn thảo "QUYẾT ĐỊNH NÂNG LƯƠNG" và sử dụng tính năng trộn thư (Mail Merge).
- [ ] **Bài 5:** Thiết lập các cụm từ gõ tắt (AutoCorrect) cho văn bản hành chính.
- [ ] **Bài 6:** Trình bày cấu trúc báo cáo nghiên cứu khoa học (Tạo trang bìa, mục lục tự động, đánh số trang).

## BÀI THỰC HÀNH SỐ 7: SỬ DỤNG PHẦN MỀM BẢNG TÍNH (EXCEL)
### 2.1. Bài tập có hướng dẫn
- [ ] **Bài 1 - Bảng lương T8:** Tính lương, dùng hàm IF tính tiền tăng ca, hàm SUM tính tổng.
- [ ] **Bài 2 - Bảng điểm:** Dùng AVERAGE, MAX, MIN, COUNT, RANK xếp hạng, IF/AND xếp loại và học bổng.
- [ ] **Bài 3 - Bảng lương T9:** Dùng VLOOKUP tra cứu phụ cấp, IF/AND, LEFT trích xuất đơn vị.
- [ ] **Bài 4 - KQ Tuyển sinh:** Hàm VLOOKUP lấy điểm ưu tiên, COUNTIF đếm số lượng, FILTER lọc danh sách, vẽ biểu đồ.
- [ ] **Bài 5 - Bảng lương công nhân:** Hàm SUM, COUNTIF đếm ngày nghỉ, IF/AND tính thưởng, vẽ biểu đồ.
### 2.2. Bài tập luyện tập
- [ ] **Bài 1 - Hóa đơn linh kiện:** Dùng hàm điều kiện, FILTER lọc danh sách, vẽ biểu đồ tỷ lệ.
- [ ] **Bài 2 - Cửa hàng nông sản:** Dùng MID, VLOOKUP tính đơn giá, hàm Subtotal tổng hợp, vẽ biểu đồ.
- [ ] **Bài 3 - Bảng tính tiền điện:** Dùng hàm dò tìm tính định mức, đơn giá, hàm COUNTIF thống kê.
- [ ] **Bài 4 - Chuyến du lịch:** Dùng VLOOKUP/bảng tham chiếu tính chi phí ăn ở và phương tiện.

## BÀI THỰC HÀNH SỐ 8: XỬ LÝ VÀ PHÂN TÍCH DỮ LIỆU SỐ
### 2.1. Bài tập có hướng dẫn
- [ ] **Bài 1 - Tiền phòng:** Dùng INT tính tuần, MOD tính ngày lẻ, VLOOKUP, Subtotal.
- [ ] **Bài 2 - Thuê máy tính:** Tính thời gian giờ/phút, tiền giảm, dùng Subtotal thống kê.
- [ ] **Bài 3 - Báo cáo BĐS:** Sử dụng LEFT, HLOOKUP, kết hợp VLOOKUP/INDEX+MATCH.
- [ ] **Bài 4 - Điểm tuyển sinh:** Dùng VLOOKUP, IF/AND, COUNTIF, FILTER và tạo Pivot Table.
- [ ] **Bài 5 - Đơn hàng:** Thực hành chuyên sâu hàm INDEX kết hợp MATCH để truy xuất dữ liệu.
### 2.2. Bài tập luyện tập
- [ ] **Bài 1 - Thuê kho:** Dùng HLOOKUP tra đơn giá, FILTER lọc theo đa điều kiện.
- [ ] **Bài 2 - Bảng kết toán:** Dùng hàm YEAR, tính tiền giảm theo khoảng thời gian.
- [ ] **Bài 3 - Danh sách đơn hàng:** Dùng hàm INDEX + MATCH trích xuất thông tin sản phẩm.
- [ ] **Bài 4 - SV Khoa KHXH:** Tính điểm ưu tiên, tạo Pivot Table phân tích dữ liệu, vẽ biểu đồ.
