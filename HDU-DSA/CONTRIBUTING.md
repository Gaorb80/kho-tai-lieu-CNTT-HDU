# 🔰 Hướng Dẫn Đóng Góp & Đồng Bộ Tài Liệu (ĐƠN GIẢN CHO NGƯỜI MỚI)

Chào bạn! Đừng lo lắng nếu đây là lần đầu bạn dùng GitHub. Quy trình dưới đây cực kỳ dễ làm, không cần gõ lệnh rườm rà và giúp chúng ta cùng tổng hợp tài liệu học tập mà không bao giờ sợ mất code hay đè file của nhau.

---

## 📥 1. Công cụ cần chuẩn bị (Chỉ cần tải 2 ứng dụng này)

Trước khi bắt đầu, bạn chỉ cần tải và cài đặt 2 công cụ hoàn toàn miễn phí sau:

1. **GitHub Desktop:** [Tải tại đây (desktop.github.com)](https://desktop.github.com/) 
   * *Công cụ bấm nút trực quan, giúp bạn đẩy và kéo tài liệu về máy dễ dàng mà không cần gõ lệnh.*
2. **VS Code (hoặc Obsidian / Notepad++):** [Tải VS Code tại đây](https://code.visualstudio.com/)
   * *Trình soạn thảo nhẹ nhàng để bạn viết note, chỉnh sửa bài tập hoặc gõ tài liệu Markdown.*

---

## 🛠️ 2. Quy trình 4 bước đóng góp cực dễ qua Fork

### Bước 1: Đồng bộ tài liệu mới nhất (Sync Upstream)
> 💡 **Luôn làm bước này đầu tiên** để lấy các ghi chú mới nhất mà mọi người vừa cập nhật!

1. Truy cập trang Web Repo Fork của bạn $\rightarrow$ Bấm nút **Sync fork** $\rightarrow$ **Update branch**.
2. Mở **GitHub Desktop**, chọn nhánh `main` $\rightarrow$ Bấm **Fetch origin** (hoặc **Pull origin**) để kéo tài liệu mới về máy.

### Bước 2: Tạo nhánh mới & Thêm tài liệu
1. Trên GitHub Desktop, bấm **Current Branch** $\rightarrow$ **New Branch** $\rightarrow$ Đặt tên nhánh ngắn gọn (Ví dụ: `note-chuong-1`, `bai-tap-lap-trinh`).
2. Mở VS Code hoặc Obsidian (editor bạn thích) để viết note, thêm bài tập hoặc tổng hợp tài liệu.

### Bước 3: Lưu (Commit) & Tải lên (Push)
1. Mở lại **GitHub Desktop**, tick chọn file bạn vừa thêm/sửa.
2. Điền ghi chú ngắn tại ô **Summary** ở góc dưới (VD: *Thêm note Chương 1 Kiến trúc máy tính*).
3. Bấm **Commit to...** $\rightarrow$ Bấm **Publish branch** (hoặc Push origin).

### Bước 4: Gửi bài (Tạo Pull Request)
1. Bấm nút **Create Pull Request** xuất hiện ngay trên GitHub Desktop (app sẽ tự mở trang Web).
2. Bấm nút **Create pull request** trên Web để gửi bài.
3. Bảo sẽ nhận được thông báo, kiểm tra và gộp (Merge) tài liệu của bạn vào kho chung của nhóm!
