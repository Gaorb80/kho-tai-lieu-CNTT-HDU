# Giải bài tập  ĐÁP ÁN: PHÂN TÍCH ĐỘ PHỨC TẠP THỜI GIAN THỰC HIỆN

**Quy ước chung:** Ta chọn _phép toán tích cực_ (active operation) làm đơn vị đếm — thường là phép so sánh, phép gán, hoặc phép toán số học nằm trong thân vòng lặp trong cùng. Gọi T(n) là số lần thực hiện phép toán tích cực. Ta phân tích T(n) theo n rồi suy ra bậc tăng trưởng O(·) (đôi khi là Θ(·) vì các đoạn này không phụ thuộc dữ liệu đầu vào, chỉ phụ thuộc n).

---

## Câu 1

```
for (int i = 1; i <= n; i++)
    if (i % 2 == 0) c++;
```

- Vòng `for` thực hiện đúng **n lần lặp**, không phụ thuộc điều kiện rẽ nhánh bên trong.
- Mỗi lần lặp, ta thực hiện: 1 phép so sánh `i<=n`, 1 phép kiểm tra `i%2==0`, và có thể 1 phép tăng `c++` (chỉ xảy ra khi i chẵn).
- Vì phép kiểm tra `i%2==0` được thực hiện **ở mọi lần lặp** (bất kể true/false), số phép toán tích cực là:

$$T(n) = \sum_{i=1}^{n} 1 = n$$

**Kết luận:** T(n) = n ⟹ **O(n)** (tuyến tính). Đây là trường hợp _best-case = worst-case_ vì vòng lặp không thoát sớm — độ phức tạp không phụ thuộc dữ liệu.

---

## Câu 2

```
for (int i = 1; i <= n; i++) {
    if (i % 2 != 0) c1++; else c2++;
}
```

- Cấu trúc `if-else` đảm bảo **đúng một nhánh** được thực hiện ở mỗi vòng lặp, không có "chi phí ẩn" như câu 1.
- Vòng lặp chạy đúng n lần, mỗi lần chi phí O(1).

$$T(n) = \sum_{i=1}^{n} 1 = n$$

**Kết luận: O(n)**. (Cụ thể c1 = ⌈n/2⌉, c2 = ⌊n/2⌋, nhưng độ phức tạp không quan tâm giá trị mà quan tâm số lần lặp).

---

## Câu 3

```
for (int i = 1; i <= n; i++)
    if (i % 2 == 0)
        for (int j = 1; j <= n; j++) c++;
```

- Vòng ngoài chạy n lần. Với mỗi i, điều kiện `i%2==0` chi phí O(1); nếu đúng (xảy ra với ⌊n/2⌋ giá trị i chẵn) thì vòng trong chạy **đủ n lần**.
- Đây là vòng lặp lồng nhau **có điều kiện**, không phải mọi i đều kích hoạt vòng trong, nhưng khi kích hoạt thì chi phí là n (không giảm dần theo i như tam giác Gauss).

$$T(n) = \underbrace{n}_{\text{kiểm tra i chẵn/lẻ}} + \left\lfloor \frac{n}{2} \right\rfloor \cdot n \approx \frac{n^2}{2}$$

**Kết luận:** T(n) = Θ(n²/2) ⟹ **O(n²)** (bậc hai). Lưu ý: dù chỉ một nửa số i kích hoạt vòng trong, hằng số 1/2 không ảnh hưởng đến bậc tăng trưởng tiệm cận.

---

## Câu 4

```
for (int i = 1; i <= n; i++) { a++; b += i; c += i*i; }
```

- Vòng lặp đơn, chạy n lần, mỗi lần thực hiện **3 phép toán hằng số** (1 tăng, 1 cộng, 1 nhân + 1 cộng).

$$T(n) = \sum_{i=1}^{n} 3 = 3n$$

**Kết luận:** 3n = **O(n)**. Hằng số nhân (3) bị loại bỏ khi lấy tiệm cận.

---

## Câu 5

```
int i = n; d = 0;
while (i > 0) { i--; d += i; }
```

- Biến điều khiển i giảm dần 1 đơn vị mỗi vòng, từ n về 0 ⟹ số vòng lặp đúng bằng **n**.
- Mỗi vòng chi phí O(1).

$$T(n) = \sum_{i=1}^{n} 1 = n$$

**Kết luận: O(n)**.

---

## Câu 6

```
i = 0; d = 0;
do { i++; if (i%3==0) d += i; } while (i <= n);
```

- Đây là vòng `do-while` (kiểm tra điều kiện _sau_), thực hiện tối thiểu 1 lần.
- i tăng từ 1 đến n+1, vòng lặp dừng khi i = n+1 (không thỏa `i<=n`) ⟹ số lần lặp = **n + 1 ≈ n**.
- Mỗi lần lặp chi phí O(1) (kiểm tra chia hết 3 là hằng số).

$$T(n) = n + 1$$

**Kết luận:** O(n+1) = **O(n)**.

---

## Câu 7

```
for (int i = 1; i <= n-1; i++)
    for (int j = i+1; j <= n; j++)
        d++;
```

- Vòng trong với i cố định chạy từ j = i+1 đến n ⟹ **(n − i)** lần.
- Tổng số lần thực hiện `d++` trên toàn bộ vòng ngoài:

$$T(n) = \sum_{i=1}^{n-1} (n-i) = (n-1) + (n-2) + \dots + 1 = \frac{n(n-1)}{2}$$

**Kết luận:** T(n) = n(n−1)/2 = (n² − n)/2 ⟹ **O(n²)** (đây chính là số cặp (i, j) với i < j — bài toán "tam giác Gauss" kinh điển).

---

## Câu 8

```
for (int i = 1; i <= n-2; i++)
    for (int j = i+1; j <= n-1; j++)
        for (int k = j+1; k <= n; k++)
            d++;
```

- Đây là bộ ba lồng nhau sinh ra tất cả các bộ (i, j, k) thỏa 1 ≤ i < j < k ≤ n.
- Số bộ ba như vậy chính là tổ hợp chập 3 của n phần tử:

$$T(n) = \binom{n}{3} = \frac{n(n-1)(n-2)}{6}$$

**Chứng minh nhanh bằng tổng ba lớp:** $$T(n)=\sum_{i=1}^{n-2}\sum_{j=i+1}^{n-1}\sum_{k=j+1}^{n} 1=\sum_{i=1}^{n-2}\sum_{j=i+1}^{n-1}(n-j)=\sum_{i=1}^{n-2}\binom{n-i}{2}=\binom{n}{3}$$

**Kết luận:** T(n) = Θ(n³/6) ⟹ **O(n³)** (bậc ba).

---

## Câu 9

```
d = 0;
while (n > 0) { n = n/2; d++; }
```

- Đây **không phải** vòng lặp giảm dần theo cấp số cộng mà giảm theo **cấp số nhân** (chia đôi ở mỗi bước, phép chia nguyên).
- Sau k bước, giá trị n còn lại là ⌊n / 2^k⌋. Vòng lặp dừng khi n = 0, tức khi:

$$\frac{n}{2^k} < 1 \iff k > \log_2 n$$

- Vậy số lần lặp d = ⌈log₂(n+1)⌉ ≈ log₂n.

**Kết luận:** T(n) = **O(log n)** (độ phức tạp logarit — đặc trưng của các thuật toán "chia đôi" như tìm kiếm nhị phân).

---

## Câu 10

```
s = 1; p = 1;
for (int i = 1; i <= n; i++) { p = p * x / i; s += p; }
```

- Vòng lặp đơn chạy n lần, mỗi lần thực hiện số phép toán **hằng số cố định**: 1 phép nhân, 1 phép chia, 1 phép cộng (không phụ thuộc i hay n).

$$T(n) = \sum_{i=1}^{n} 3 = 3n$$

**Kết luận: O(n)**. (Đây thực chất là công thức tính gần đúng eˣ bằng khai triển Maclaurin, nhưng về độ phức tạp thuật toán, ta chỉ quan tâm số vòng lặp).

# Giải bài tập youtube (Câu khó hơn)  PHÂN TÍCH ĐỘ PHỨC TẠP THỜI GIAN THỰC HIỆN — `count_1(int N)`

## 1. Xác định phép toán tích cực (basic operation)

Trong đoạn chương trình, thao tác được thực hiện lặp đi lặp lại và quyết định trực tiếp đến thời gian chạy là câu lệnh:

```
sum++
```

Đây chính là **phép toán tích cực (basic operation)** cần đếm số lần thực hiện, vì mọi lệnh khác (khởi tạo, so sánh điều kiện vòng lặp, tăng biến điều khiển) đều có chi phí O(1) và tỉ lệ thuận với số lần lặp của `sum++`.

## 2. Thiết lập biểu thức đếm số lần lặp

**Vòng lặp ngoài:** biến `i` chạy từ `1` đến `n`.

**Vòng lặp trong (phụ thuộc `i`):** biến `j` chạy từ `i` đến `n`, do đó với mỗi giá trị `i` cố định, vòng lặp trong thực hiện:

$$
n - i + 1 \text{ lần}
$$

Gọi $T(n)$ là tổng số lần thực hiện lệnh `sum++`. Ta có:

$$
T(n) = \sum_{i=1}^{n} (n - i + 1)
$$

## 3. Tính tổng — Biến đổi toán học

Đặt $k = n - i + 1$. Khi $i = 1 \Rightarrow k = n$; khi $i = n \Rightarrow k = 1$. Do đó:

$$
T(n) = \sum_{k=1}^{n} k = 1 + 2 + 3 + \dots + n
$$

Áp dụng công thức tổng cấp số cộng (Gauss):

$$
T(n) = \dfrac{n(n+1)}{2} = \dfrac{n^2}{2} + \dfrac{n}{2}
$$

**Kiểm chứng nhanh (n = 3):**
- i=1: j chạy 1→3 → 3 lần
- i=2: j chạy 2→3 → 2 lần
- i=3: j chạy 3→3 → 1 lần
- Tổng = 3+2+1 = 6 = 3·4/2 ✓

## 4. Đánh giá độ phức tạp tiệm cận (Asymptotic Analysis)

Ta có:

$$
T(n) = \dfrac{1}{2}n^2 + \dfrac{1}{2}n
$$

Khi $n \to \infty$, số hạng bậc cao nhất $\dfrac{1}{2}n^2$ **chi phối (dominate)** toàn bộ biểu thức; số hạng bậc thấp $\dfrac{1}{2}n$ trở nên không đáng kể. Theo định nghĩa Big-O, bỏ qua hệ số nhân và các số hạng bậc thấp, ta được:

$$
\boxed{T(n) = O(n^2)}
$$

**Chứng minh chặt chẽ theo định nghĩa Big-O:** cần chỉ ra tồn tại $c > 0, n_0 \ge 1$ sao cho $T(n) \le c \cdot n^2 \;\forall n \ge n_0$.

Chọn $c = 1$, $n_0 = 1$: với mọi $n \ge 1$,

$$
T(n) = \dfrac{n^2}{2} + \dfrac{n}{2} \le \dfrac{n^2}{2} + \dfrac{n^2}{2} = n^2 \quad (\text{vì } n \le n^2 \text{ khi } n\ge1)
$$

Vậy $T(n) \le 1 \cdot n^2$ với mọi $n \ge 1$ ⟹ $T(n) = O(n^2)$. ∎

*(Đây cũng là chặn dưới $\Omega(n^2)$ vì $T(n) \ge \frac{n^2}{2}$, nên thực chất $T(n) = \Theta(n^2)$ — độ phức tạp bậc hai chặt.)*

## 5. Kết luận

| Tiêu chí             | Kết quả                                                          |
| -------------------- | ---------------------------------------------------------------- |
| Loại vòng lặp        | Vòng lặp lồng nhau, cận trong phụ thuộc biến ngoài (tam giác)    |
| Công thức chính xác  | $T(n) = \dfrac{n(n+1)}{2}$                                       |
| Độ phức tạp tiệm cận | $\Theta(n^2)$ (thường viết $O(n^2)$)                             |
| Lớp bài toán         | Đa thức bậc 2 — chậm hơn vòng lặp đơn $O(n)$, nhanh hơn $O(n^3)$ |

**Ghi chú sư phạm:** Lỗi thường gặp của sinh viên là chấm điểm ngay $O(n^2)$ chỉ vì "thấy 2 vòng `for` lồng nhau" mà không thiết lập tổng $\sum$ tường minh. Với vòng lặp trong có cận phụ thuộc biến ngoài (dạng tam giác như bài này), bắt buộc phải viết biểu thức tổng $\sum_{i=1}^n(n-i+1)$ và biến đổi ra công thức đóng (closed-form) trước khi kết luận bậc tiệm cận — đó là điều giám khảo tìm kiếm để cho điểm tối đa.
